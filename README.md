# Java Frontend (React + TypeScript + Vite)

Frontend application for the **Spring Boot Student Management Backend** (`Practice-2`).

### Quick Start
```bash
npm install
npm run dev
```

Visit: `http://localhost:5173`

### Scripts
- `npm run dev` - Start Vite dev server with proxy to `http://localhost:8080`
- `npm run build` - Type check and build production bundle
- `npm run lint` - Run ESLint checks
- `npm run preview` - Preview production build locally

For full documentation and API endpoint mapping, see the [Root README](../README.md).
